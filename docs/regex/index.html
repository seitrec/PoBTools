Matches mod names, so it works on identified magic flasks; the name tells the tier apart. Checked against every flask mod name, flask mod text and flask base name from poedb: it hits the mods above and nothing else. Life and mana flasks with the same prefixes (Perpetual, Surgeon's…) match too, and the short fragments will light up other kinds of items, so use it on a flask tab. Left out on purpose: reduced effect, maximum charges, immunities, block and stun recovery, leech, freeze/shock/ignite chance, reduced effect of X on you, and avoid chill/freeze/ignite.
